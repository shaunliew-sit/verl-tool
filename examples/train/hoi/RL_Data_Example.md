# HOI RL Data Example

This document shows example data samples generated by `prepare_hoi.py` for RL training.

## Data Format

Each sample in the parquet file contains:
- `data_source`: Dataset identifier (e.g., `"hico_det"`, `"swig_det"`)
- `prompt`: Multi-turn conversation (system + user)
- `images`: List of image paths
- `ability`: Task type (`"referring"` or `"grounding"`)
- `reward_model`: Ground truth and task metadata
- `extra_info`: Additional metadata (boxes, indices, etc.)

---

**Key Points**:

- Output format must match: `[{"bbox_2d": [x1, y1, x2, y2], "label": "..."}, ...]`

## Expected Model Response Format

### Referring Task Response
The model should output a short action phrase:
```
holding baseball bat
```

Or with tool usage:
```
<think>
I need to examine the interaction between the person and the object more closely.
</think>

<tool_call>
{"name": "zoom_in", "arguments": {"bbox_2d": [400, 200, 650, 500], "target_image": 1}}
</tool_call>

[Observation: Zoomed into region...]

<answer>
holding baseball bat
</answer>
```

### Grounding Task Response
The model should output JSON-formatted bounding boxes:
```json
[{"bbox_2d": [353, 39, 532, 456], "label": "person"}, {"bbox_2d": [272, 141, 615, 956], "label": "bicycle"}]
```

Or with tool usage:
```
<think>
I need to detect all bicycles and people in the image first.
</think>

<tool_call>
{"name": "detect_objects", "arguments": {"class_names": "person . bicycle", "target_image": 1}}
</tool_call>

[Observation: Detected objects: person at [353, 39, 532, 456], bicycle at [272, 141, 615, 956]...]

<answer>
[{"bbox_2d": [353, 39, 532, 456], "label": "person"}, {"bbox_2d": [272, 141, 615, 956], "label": "bicycle"}]
</answer>
```

## Reward Computation

### Referring Task
- **Reward Function**: `referring_score_v2()`
- **Scoring**:
  - Verb mismatch → **0.0**
  - Verb match + exact phrase → **1.0**
  - Verb match + partial object → **0.5 + 0.5 × overlap**

**Example**:
- GT: `"holding baseball bat"`
- Pred: `"holding bat"` → Score: **0.5 + 0.5 × (1/2) = 0.75**
- Pred: `"riding baseball bat"` → Score: **0.0** (verb mismatch)

### Grounding Task
- **Reward Function**: `grounding_score()`
- **Scoring**: Binary reward
  - All GT boxes matched (IoU ≥ 0.5) → **1.0**
  - Otherwise → **0.0**

**Example**:
- GT: `[{"bbox_2d": [353, 39, 532, 456], "label": "person"}, {"bbox_2d": [272, 141, 615, 956], "label": "bicycle"}]`
- Pred: `[{"bbox_2d": [350, 40, 530, 455], "label": "person"}, {"bbox_2d": [270, 140, 620, 960], "label": "bicycle"}]`
- IoU(person): 0.95, IoU(bicycle): 0.92 → Score: **1.0** ✓

---

## Notes

1. **Coordinate System**: All bounding boxes use 1000×1000 normalized coordinates (not pixel coordinates)
2. **Image Paths**: Absolute paths stored in `images[0].image`
3. **Tool Calls**: Must be wrapped in `<tool_call>...</tool_call>` tags
4. **Multi-turn**: Model can use tools up to `max_turns=3` times
5. **Ground Truth Format**: 
   - Referring: Simple string (`"holding baseball bat"`)
   - Grounding: JSON string (`"[{...}, {...}]"`)
